# 2026-10-31 UI・待機広場・投石の確認

## 実装
- 待機広場：Canvas 2Dで焚き火・洞穴・ゴブリンを表示。クリック／タップ／WASD移動を同じ部屋へ同期。
- 部屋チャット：自由文100文字・定型文3種、キャラの吹き出し。直近30件・送信間隔800ms。DOMはtextContentで描画。
- ゴブリンHUD：3Dを広く表示、HPとEXPを常設、進化／作戦／報酬はタブ式。
- カメラ：追従／近め／俯瞰、左右45度、背後リセット。Vキーでもプリセット切り替え。
- 技②投石：5秒CD、2／Eキーまたはボタン、前方または選択対象へ発射。弾速7・射程9。ゴブリンへ2ダメージと0.35秒ひるみ、勇者へ6ダメージ。通常攻撃とは別CD。壁で停止、子ゴブリンの同族保護を維持。

## 確認結果
- 実画面2人：固定部屋作成→参加→WASDで広場を移動→自由文・定型文を双方に受信→吹き出しを表示。
- 同じ部屋からラウンド準備へ移行、ゴブリン3D表示、近め／俯瞰へ切り替え。
- 投石ボタンで発射、残り4.8秒などCD表示→再使用可能。弾の描画も確認。
- 進化パネル→探索へ戻る→WASD移動→Eで投石→ラウンド中断で広場へ帰還。
- 390×780のスマホ幅でジョイスティック／通常攻撃／投石／カメラ／HPの配置を確認。投石ボタンを実操作。
- ブラウザconsole errorなし。
- 自動テスト48件成功、npm run build成功。新規4件はロビーの移動・チャット・再接続と、投石の命中・CD・壁・子保護・回避。
